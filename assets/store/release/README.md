# Google Play release assets

Use the `free/` folder for **Opcode Arena** and `circuit/` for
**Opcode Arena: The Circuit**. Do not mix assets between listings.

Use `fireline/` for **Opcode FIRELINE**. Its three authentic 1080x2400
emulator captures live under `fireline/screenshots/`; the `*-play.png`
copies preserve the full captures inside an exact 1080x1920 (9:16) canvas for
Google Play upload. FIRELINE currently ships three screenshots rather than the
five used by the Arena listings.

Each folder contains:

- `icon-512.png` — 512×512, 32-bit PNG;
- `feature-graphic-1024x500.png` — 1024×500, 24-bit RGB PNG;
- five 24-bit RGB portrait phone screenshots in intended display order;
- `release-notes-en-US.txt` — paste-ready first-release notes.
- `alt-text-en-US.txt` — suggested accessible descriptions for upload.

The free set uses the phosphor-green robot. The Circuit set uses the amber
robot and amber paid-tier markers while the shared terminal/game system stays
green. Screenshot pixels are direct app captures; no marketing captions or
device frames have been added.
